## Scope reconciliation
Microsoft's specific Outlook-chat guidance documents limited inbox questions without an add-on. The declarative-agent capability table separately labels Email knowledge as license only. These concern different runtime paths; do not apply the custom-agent restriction to every Outlook chat. Generic overview/FAQ wording may differ; use the specific current feature page and actual capability test. Neither statement establishes exhaustive access or an unattended service.

The individual embedded-knowledge file list includes TXT/PDF, not this handoff ZIP. An actual agent-skill ZIP is a different artifact type with its own packaging rules; this bundle does not claim to be one. In version 3, first-use reading needs no uploads at all.
