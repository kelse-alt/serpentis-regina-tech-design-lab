# Personal Outlook Email Assistant

**Beginner Edition v3.0 - prepared by Amaya Kelsea Hunt.**

A reusable setup package for personal Outlook email reviews, role-aware onboarding, action lists and unsent drafts. The core works across job roles; apparel technical-design material is optional.

## Start here

1. **[Download the complete ZIP](downloads/Personal_Outlook_Email_Assistant_v3_0.zip?raw=true)** and extract it.
2. Open **[00_START_HERE.pdf](00_START_HERE.pdf)** for the three starting steps.
3. From Outlook Mail/Inbox, open the built-in Copilot chat and paste **[01_START_IN_OUTLOOK.txt](01_START_IN_OUTLOOK.txt)**.

The first route requires no package/reference/test upload. A custom agent is optional and has its own account/source requirements. Follow the guide's capability checks rather than assuming every account has identical features.

## What changed in v3

- A single beginner starting path, with a separate optional custom-agent route.
- New-starter and established-employee onboarding.
- Clear group instructions distinguished from passive To/CC inclusion.
- Ownership uncertainty separated from completion uncertainty.
- Completed work retained in history, outside current priorities.
- Latest-reply, deadline/cutoff and attachment checks before drafts.
- Compact reviews and a reviewed handoff for another conversation.
- Role-neutral instructions plus optional [technical-design material](OPTIONAL_TECHNICAL_DESIGN/00_READ_FIRST.txt).

## Scope and readiness

The default is **on-demand reading and drafts displayed in chat**. Sending, Outlook-draft creation, mailbox/calendar changes, WIP/PLM writes and background monitoring remain disabled unless separately configured and authorized. Search previews are not complete historical mailbox audits. A conversation is not an unattended service or proof of permanent memory.

For fuller integration, see [FOR_BUILDERS](FOR_BUILDERS/00_READ_BEFORE_BUILDING.md). For optional validation, see [TESTS](TESTS/00_HOW_TO_CHECK.md). The package includes 32 new expected-behavior scenarios and 48 preserved advanced cases; they are not claimed as passing company-tenant/model tests. Local validation results are in the [validation report](FOR_BUILDERS/07_Validation_Report.md).

## Package integrity and data

The original ZIP, standalone guide and instruction file are stored in `downloads/`. [SHA256SUMS](SHA256SUMS) records their checksums. The original [manifest](manifest.json) verifies files inside the distributed package. PDF provenance/metadata can differ between the standalone download and the PDF inside the ZIP; their ten pages have matching extracted text.

Examples are fictional or generalized. No workplace emails, colleague identities, private mailbox links, credentials or screenshots are included. Use real correspondence only in your own approved work environment. The original house measurement case study elsewhere in this repository remains separate from this Outlook package.
