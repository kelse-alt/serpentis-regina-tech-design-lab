# Serpentis Regina — Technical Design Lab 🐍

**Building fashion technology through practical JavaScript case studies.**

This is a **public learning and portfolio repository** documenting the development of reusable technical-design code, progressing toward a private PLM-style system for the Serpentis Regina fashion house.

## Start here

**[Case Study 001: Mannequin Measurement Comparison](case-studies/01-mannequin-measurement-registry/README.md)** — an executable, tested JavaScript demonstration of Points of Measure (POM), structured records, approved house standards and manufacturer-reference differences.

```bash
npm run demo
npm test
```

Requires Node.js 20 or later. No third-party dependencies needed.

## Development path

1. **House fit-form registry** — measurement records, validation, reference comparison (in progress)
2. **Digital style/tech-pack records** — pattern cards, garment measurement specs, fit/comments
3. **Grading and sample versioning** — grade rules, before/after wash data, change tracking
4. **Internal PLM dashboard** — secure database and browser interface
5. **Web and workflow integrations** — future tools for house operations

## Data and IP policy

All public measurements are **fabricated educational examples**. No confidential tech packs, approved production standards, client details, employment materials or credentials should be committed here. The production house data and its approval/revision history are maintained in a separate **private** repository. A manufacturer-reference difference is **not** a tolerance check.

Built incrementally as a learning archive. Early-stage prototype; not a deployed or production-ready PLM system.
